# Advanced Forecasting (Time Series) - Power BI Project

##  Project Overview

This project focuses on financial forecasting using Power BI, combining time series analysis with FP&A (Financial Planning & Analysis) concepts.

The dashboard provides a structured approach to forecasting revenue, costs, and margins, while highlighting key business drivers.

---

##  Objectives

- Forecast revenue based on historical trends
- Estimate future costs using growth assumptions
- Analyze projected margin performance
- Compare different forecasting methodologies
- Identify key drivers impacting profitability

---

##  Dataset

The dataset includes:
- Historical revenue and cost data (2023–2024)
- Customer and product-level transactions
- Cost structure components (variable, fixed, marketing)
- Time series structure for forecasting
